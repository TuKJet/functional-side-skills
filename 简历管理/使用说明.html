招聘工作台 / 使用指南

管理招聘，只记住三件事。

第一次安装交给 Agent。配置完成后，日常不用命令，也不用填系统表单。

01 / 维护与审核

直接问 WorkBuddy

打开本地任务，把简历、岗位要求或要改的进展告诉它。审核结果由你复核。

02 / 查看进展

打开「招聘工作台」

Agent 会帮你下载并配置客户端，还会问你是否需要桌面快捷方式。Windows 用 EXE，Mac 用应用程序，打开就能查看进展。

03 / 与同事同步

点击「一键同步」

已配置公司共享空间后，开始和结束工作时各点一次。断网时继续在本机工作。

不知道怎么说？照着这几句就行。

收简历请把这个文件夹里的简历加入简历池，保留原件，重复的先告诉我。
建岗位这是本月的招聘要求，请登记部门、岗位和人数，整理审核标准给我确认。
审简历请按这个岗位的要求审核待处理简历，列出匹配点、缺少的证据和建议排序，供我复核。
记面试请保存这份二面评价表，登记评价人、日期、意见，并更新候选人的进展。
用 Excel请导出总台账；我修改好进度后，再帮我回写并同步。
处理冲突同步提示有冲突，请列出我和同事改了什么，等我选择后再处理。
还未安装？把本文件夹交给安装 Agent，让它先读 README 和 安装指南。
共享空间尚未配置时先本机使用。同步失败不会撤销已保存的本地工作；不确定时直接把提示发给 WorkBuddy。
