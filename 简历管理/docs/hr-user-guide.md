# 招聘工作台：给职能同事的一页说明

## 只记住三件事

1. **录入、修改、审核：问 WorkBuddy。** 把简历文件夹、岗位说明或要改的内容直接告诉它。
2. **查看：Windows 双击“招聘看板.exe”，Mac 双击“招聘看板.app”。** 会打开独立窗口，直接在窗口内显示看板。这里看总览、搜索、简历详情、审核证据、二面评价和同步情况。
3. **同步：点“一键同步”。** 平时在本机工作；有网时点一下把进展送到公司共享空间。没有网络也可以继续工作，恢复后再同步。

看板是查看用的，不需要在窗口里填写表格，也没有技术设置页面。招聘结论始终由 HR 决定；系统不会因为某项没有证据就自动淘汰候选人。关闭主窗口会结束本次服务；再次双击会激活已有窗口。

如果 WorkBuddy 弹出权限确认，这是它请求访问本机 Python、文件夹或 NAS 的客户端授权；它不是招聘网页的业务录入或评审弹窗。

## 可以直接复制给 WorkBuddy 的话

每句话可以单独使用：

- 请把这个文件夹里的简历全部加入本地简历池，保留原件和来源，重复文件不要覆盖。
- 请按本月的机械设计工程师岗位要求审核待处理简历；逐项引用简历原文，没有证据的地方标记待核实，不要自动淘汰。
- 请登记这名候选人的二面：评价人是……，日期是……，结论是……，附件在……。
- 请把这条招聘进展改为“二面”，负责人是……，下一步日期是……。
- 请导出招聘总台账；我改完进度后，把修改回写并告诉我是否同步成功。
- 请检查同步；如果有冲突，请列出本机和共享空间的两个版本，先不要覆盖，等我选择。
- 请检查 HR Skill 和招聘客户端更新，保留我的工作资料和配置；有客户端新版时下载对应系统版本并协助升级。

## 两种异常说法

- 窗口打不开：**“请检查招聘工作台是否启动，并告诉我启动错误。”**
- 看不到简历文字：**“请保留原件，并告诉我如何补充人工核对文字。”**
